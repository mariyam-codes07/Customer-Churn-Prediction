# Customer Churn Prediction 📊

A machine learning project that predicts whether a customer is likely to churn (leave the service) using the Telco Customer Churn dataset.

## 📌 Project Overview

Customer churn means a customer stops using a company's service.

In this project, machine learning is used to predict customer churn based on customer information such as:

- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Phone Service
- Internet Service
- Online Security
- Online Backup
- Device Protection
- Tech Support
- Contract
- Paperless Billing
- Payment Method
- Monthly Charges
- Total Charges

## 🎯 Objective

The main objective of this project is to build a machine learning model that can predict:

- `0` → No Churn
- `1` → Churn
